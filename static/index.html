Modelo 1 • Baseline

Regressão Linear (Ridge)

Assume que o preço é uma soma ponderada direta dos atributos. É ultrarrápido (0.04s), mas não capta efeitos não-lineares, resultando em um erro percentual maior (~27%).

Modelo 2 • Não-Linear

Árvore de Decisão Simples

Cria regras condicionais de if/else para segmentar o mercado. Melhora o erro percentual (~20%), porém uma árvore isolada tem alta variância entre as dobras da validação cruzada.

Modelo 3 • Campeão 🏆

Random Forest (Ensemble)

Combina 100 árvores de decisão com subamostras aleatórias (Bagging). Reduz o ruído individual, atinge a maior acurácia explicada (89.11%) e o menor erro médio (~16.9%).

Metodologia Científica

Por que Validação Cruzada (5-Fold)?

Em vez de uma divisão única e sortuda de 80/20, os dados são divididos em 5 partes. O modelo é treinado 5 vezes, testando em cada dobra separadamente para provar robustez real.
